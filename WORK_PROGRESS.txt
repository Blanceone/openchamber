OpenChamber 本机桌面裁剪 — 工作进展与后续事项
============================================
日期：2026-08-05
分支：dev
远程：origin = https://github.com/Blanceone/openchamber.git
上游：upstream = https://github.com/openchamber/openchamber.git

一、产品目标（已确认）
--------------------
- 仅保留 Windows Electron 桌面产品面（packages/electron + web + ui）
- 本机工作为主，需要本地 Git / GitHub（含 Git SSH 身份）
- 不再提供 OpenChamber 远程主机、Private Relay、外网隧道、配对扫码连入、LAN 暴露等产品入口

二、已完成工作
--------------

【阶段 A】Windows 桌面产品裁剪（相对上游多端产品）
- 删除 packages/vscode、packages/mobile、packages/docs
- CI / release 收敛为 Windows Electron（去掉 mac/linux/mobile/vscode 工作流）
- Electron 打包目标仅 Windows NSIS
- 增加 Windows 环境辅助：bunfig.toml（hoisted linker）、scripts/windows-electron-env.ps1、repair-windows-electron.ps1
- 曾成功打出安装包（本机产物，未入库）：
  packages/electron/dist/OpenChamber-1.18.1-win-x64.exe（约 158MB，未签名）

【阶段 B】本机 + Git：裁剪 OpenChamber 远程能力（按计划）
UI：
- Settings 移除 remote-instances、tunnel；General 去掉 LAN / keep-awake / LAN UI 密码
- 删除 RemoteInstancesPage、TunnelSettings、DesktopHostSwitcher、RemoteConnectionForm
- 删除 desktopSsh / useDesktopSshStore / connectionPayload / desktopRelayRestore
- desktopHosts 收成仅本机；项目动作去掉 desktopSshForward
- Header 去掉主机切换与 remote-update；onboarding/recovery 仅本机
- 深链去掉 instances / connect；保留 session 类深链意图
- 保留 Settings → Git / GitHub（Git SSH 身份 ≠ OpenChamber SSH 主机）

Electron：
- ssh-manager 改为 no-op stub；desktop_ssh_* / 远程 host 探活与连入收窄或空实现
- 去掉 openchamber://connect 与 host/<id> 深链；保留本机 token 与 session 深链
- preload 去掉 relay host id 注入

CLI / 文档：
- openchamber tunnel / connect-url 在 cli.js 入口直接报错退出（本地桌面构建禁用）
- 更新 README.md、AGENTS.md、packages/electron/README.md、packages/web/README.md

验证（已跑）：
- node --check：electron main / preload / ssh-manager
- bun test：ssh-manager stub、desktopHosts、desktopRecoveryRouting、CLI 禁用相关用例
- bun run dead-code（非阻塞报告）
- 说明：packages/ui 全量 tsc 仍有原有 process/@types/node 问题，与本次删除无直接对应报错

四、建议后续工作事项
--------------------

1. 本机冒烟：bun run electron:dev

2. 在具备 VS Build Tools 的环境完整跑 electron:build，产出可分发安装包并做安装冒烟
3. 跟进删除（或 feature-flag 404）web tunnels/relay/pairing 路由与 ui/lib/relay，减小攻击面与包体

6. 评估 DesktopNetworkSettings 去掉本地 UI 密码后，是否仍需独立的本机锁屏密码设置
