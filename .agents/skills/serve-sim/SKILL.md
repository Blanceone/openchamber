# serve-sim (removed)

`packages/mobile` and the Capacitor iOS product surface were removed from this monorepo. The Windows desktop product does not use `serve-sim`.

If you need simulator streaming again, restore the mobile package from upstream history first. Do not invent a local substitute under `packages/electron`.
